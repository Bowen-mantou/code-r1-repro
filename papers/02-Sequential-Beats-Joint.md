# Sequential Beats Joint（arXiv 2609.04108，UAlberta/NYU 等，2026-09-03）

**一句话**：OPD-then-RL **串行**一致优于纯 OPD、纯 RLVR 和**所有 joint（并行融合）基线**——这是对用户 E9 方案的最强直接支撑。

## 核心发现

1. **两阶段串行方案（OPD 先、RLVR 后）在逻辑/数学推理基准上全面最优**。
2. **对 joint 方法的挑战**：此前工作把 OPD 的稠密 token 监督与 RLVR 的稀疏任务奖励
   在单步内融合（加权相加 / teacher 调制 rescale）——论文证明两信号会**互相干扰**。
3. **机制解释**（pass@k 行为 + 学习动力学 + 参数更新分析）：
   - **OPD 扩展**学生对 teacher 支持解的覆盖范围
   - **RLVR 锐化**这个扩展覆盖内的表现
   - 顺序化让两信号成为**互补阶段**；并行则互相干涉
   - 顺序影响「哪些参数配置可达」，不只是效率问题
4. **实用配方**：
   - **OPD 验证分数是「何时从 OPD 切到 RL」的关键信号**
   - **OPD 是比 SFT 更好的 RL 冷启动**（cold start）
5. 局限：只在逻辑/数学推理上验证；两阶段训练的开销未讨论。

## 对 E9 的意义

- E9 = OPD（阶段 1，E5 模型）→ RLVR+Verifier（阶段 2）正是论文验证的最优顺序 ✅
- 阶段 1 的切换信号：OPD 验证集分数（E5 的 LCB 24.7 已证明阶段 1 达标）
- 「OPD 冷启动优于 SFT」→ 用户原方案「verifier 过滤 SFT 蒸馏」可升级为 OPD 蒸馏
  （E5 模型已找回，成本反而更低）
